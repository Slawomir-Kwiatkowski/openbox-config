<p>
  Applications run maximized by default, without window decorations (<span style="color: red;">Super+q </span>to close app).</p>



<!--more--><br /><span style="">To open my apps I use key shortcuts.&nbsp;</span><div><span style="background-color: black;">My favorite apps open in specific workspaces; for example, a web browser opens on the WWW workspace.&nbsp;</span></div><div><span style="background-color: black;">Pressing Super+i switches the workspace to WWW and opens the web browser. If an app is already open, the workspace switches to that app.&nbsp;</span></div><div><br /></div><div><u><span style="">Running apps in single instance mode:</span></u><br />


<ul style="list-style-type: circle; text-align: left;">
  <li><span style="color: red;">Super + i </span>--- run one instance of web browser (Brave) on WWW desktop</li><li><span style="color: red;">Super + c</span> --- run one instance of Visual Studio Code on DEV desktop</li><li><span style="color: red;">Super + n</span> --- run one instance of NVim on DEV desktop</li><li><span style="color: red;">Super + s</span> --- opens one instance of scrapbook on DOC desktop</li><li><span style="color: red;">Super + f </span>--- run one instance of LF file manager on TOOLS desktop</li><li><span style="color: red;">Super + p</span> --- run one instance of file manager (pcmanfm)&nbsp;on TOOLS desktop&nbsp;</li></ul><div><br /></div><div><u><span style="">Running dropdown terminal:</span></u></div><ul style="list-style-type: circle; text-align: left;"><li><span style="color: red;">Super + Enter </span>--- run one instance of terminal (<u>dropdown mode</u>)&nbsp;</li></ul><div><br /></div><div><u><span style="">Closing apps and system:</span></u></div><ul style="list-style-type: circle; text-align: left;"><li><span style="color: red;">Super + q</span> --- close current app</li><li><span style="color: red;">Super + Esc</span> --- show system exit menu</li></ul><div><br /></div><div><u><span style="">Workspaces:</span></u></div><ul style="list-style-type: circle; text-align: left;"><li><span style="color: red;">Super +</span> <span style="color: red;">1 to 5</span>&nbsp;--- switch to desktop 1 to 5 (or&nbsp;<a data-preview="" href="https://www.google.com/search?ved=1t:260882&amp;q=Super+key+numpad+desktop+switching&amp;bbid=7265947002517060094&amp;bpid=4651778526338507075" target="_blank"><span style="color: red;">S</span></a><span style="color: red;">uper +&nbsp;&nbsp;NUM 1 to 5</span>)</li>
  <li><span style="color: red;">Super + LeftArrow</span> --- switch to desktop on the left (or <span style="color: red;">Super + h</span>)</li>
  <li><span style="color: red;">Super + RightArrow</span> --- switch to desktop on the right (or <span style="color: red;">Super +l</span>)</li>
  <li><span style="color: red;">Super + Shift + 1 to 5</span> --- move app to chosen desktop (or <span style="color: red;">Super + Shift + NUM 1 to 5</span>)</li>
  <li><span style="color: red;">Super + Shift + LeftArrow </span>--- move app to desktop on the left (or <span style="color: red;">Super + Shift + h</span>)</li>
  <li><span style="color: red;">Super + Shift + RightArrow</span> --- move app to desktop on the right (or <span style="color: red;">Super + Shift + l)</span>&nbsp;</li></ul><div><br /></div><div><u><span style="">App finder and system shortcuts:</span></u></div><ul style="list-style-type: circle; text-align: left;">
  <li><span style="color: red;">Super + Spacebar</span> --- run App Finder</li>
  <li><span style="color: red;">Super + MenuKey</span> --- run main LXQT menu</li></ul><ul style="list-style-type: circle; text-align: left;">
  <li><span style="color: red;">Super + Ctrl + UpArrow</span> --- <a data-preview="" href="https://www.google.com/search?ved=1t:260882&amp;q=how+to+increase+screen+brightness+shortcut&amp;bbid=7265947002517060094&amp;bpid=4651778526338507075" target="_blank">i</a>ncrease screen brightness</li>
  <li><span style="color: red;">Super + Ctrl + DownArrow</span> --- decrease screen brightness</li>
  <li><span style="color: red;">Super + F9</span> (volumeUpKey) --- <a data-preview="" href="https://www.google.com/search?ved=1t:260882&amp;q=how+to+increase+sound+volume&amp;bbid=7265947002517060094&amp;bpid=4651778526338507075" target="_blank">i</a>nsrease sound volume</li>
  <li><span style="color: red;">Super + F10</span> (volumeDownKey) --- decrease sound volume</li>
  <li><span style="color: red;">Super + F11</span> (muteSoundKey) --- mute sound</li>
  <li><span style="color: red;">Print</span> --- make screenshot</li>
</ul>


<p><br /></p><p>Terminal shortcuts:</p>

<ul style="list-style-type: circle;">
  <li><span style="color: red;">Alt + v </span>--- split terminal vertically</li>
  <li><span style="color: red;">Alt + b </span>--- split&nbsp;terminal horizontally</li>
  <li><span style="color: red;">Alt + h, j, k, l</span>&nbsp; --- move across subterminals (or <span style="color: red;">Alt + Arrows</span>)</li>
  <li><span style="color: red;">Alt + q</span> --- close tiled subterminals (<span style="color: red;">Super + q</span> to close)</li>
</ul>
